왜 만들었는지는 [가계부를 직접 만든 이유](../why-we-built-it/)에 적었어요. 이번 글은 **무엇을 어떤 순서로 만들었는지**예요. 9월 30일에 시작해서 10월 12일까지, 2주 동안의 기록입니다.

## 첫날: 쌓는 것부터

"이 돈으로 집을 살 수 있나"에 답하려면 먼저 **둘의 숫자가 쌓여야** 했어요. 그래서 계산하는 화면보다 적는 화면을 먼저 만들었어요. 첫날 만든 순서는 이래요.

1. 매일 입력: 금액, 카테고리, 결제수단, 누구
2. 고정비: 매달 자동으로 만들어 두고 금액만 확인
3. 월별 자산 잔액과 순자산 추이
4. 통계: 사람별, 고정비와 변동비
5. 목표: 이번 달 변동비 한도, 올해 저축 목표
6. 백업, 로그인, 휴대폰 홈 화면에 추가

로그인은 비밀번호 하나를 둘이 같이 써요. 기록마다 붙는 "누가 썼나"는 로그인한 사람이 아니라 **입력할 때 고르는 값**이라, 한 사람 폰으로 둘의 지출을 다 적을 수도 있어요.

그리고 처음부터 정한 게 하나 있어요. **AI 없이, 정해진 계산 규칙으로만** 동작하게 했어요. 돈 계산은 매번 같은 답이 나와야 하니까요.

## 써 보면서 고친 것

첫 주가 지나고 실제로 써 보니 고칠 게 계속 나왔어요. 대부분은 **제가 직접 쓰면서 답답했던 것**이에요. 데이터 백업, 저녁 알림, 고정비 확인 같은 것도 다 쓰다가 "이게 있어야겠다" 싶어서 넣었어요. 예비 남편이 짚어 준 것도 몇 가지 있는데, 그건 아래에 따로 모았어요.

### 순자산만으로는 판단이 안 된다

순자산이 늘어도 그 돈을 당장 쓸 수 있는 건 아니에요. 그래서 순자산 옆에 **유동 가능 금액**을 따로 보여 줘요. 원칙은 보수적으로.

| 종류 | 반영 | 이유 |
| --- | --- | --- |
| 입출금, 적금, 주식 | 100% | 바로 꺼낼 수 있음 |
| 연금, IRP | 83.5% | 중도에 깨면 16.5%를 세금으로 냄 |
| ISA | 84.6% | 15.4%를 잔액 전체에 매김 (수익을 따로 모르니까) |
| 청약 | 0% | 깨면 청약 자격이 없어지는, 깨지 않을 돈 |
| 대출 | 빼지 않음 | 당장 갚을 돈이 아니라서 |

### 저축이 안 보인다

처음엔 수입과 지출만 있었는데, 그러면 적금에 넣은 돈이 어디로 갔는지 안 보였어요. 그래서 저축을 지출이 아닌 **세 번째 흐름**으로 따로 기록하게 했어요.

> 수입 = 지출(고정비 + 변동비) + 저축·투자 + 남은 돈

이렇게 나누니 "이번 달에 얼마를 모았나"와 "얼마가 그냥 통장에 남았나"가 구분돼요.

### 잔액은 지난달 말 기준

10월 2일에 9월 말 잔액을 넣었는데, 앱은 "이번 달(10월) 잔액이 없어요"라고 경고했어요. 잔액은 그 달이 끝나야 알 수 있는 값인데 말이죠. 그래서 **잔액을 넣는 달은 지난달**로 바꾸고, 이번 달은 아예 고를 수 없게 했어요.

### 폰에서 쓰기 편하게

- 금액이 두 줄로 넘어가면 읽기 어려워서, 숫자 칸은 한 줄에 하나씩
- 목록 순서를 ↑↓ 버튼으로 하나씩 옮기는 게 번거로워서, **손잡이를 잡고 끌어서** 옮기게
- 설정이 한 화면에 길게 늘어져 있어서, 요약 카드를 누르면 세부 화면으로 들어가게

### 예비 남편이 짚어 준 것

같이 쓰는 사람이 보니 제가 못 본 게 보였어요.

- **지금 어디에 있는지**: 화면 안으로 깊이 들어가면 길을 잃는다고 해서, 하위 화면마다 경로 표시(입력 › 목표 같은)와 뒤로가기를 붙였어요. 뒤로가기는 **들어온 곳으로** 돌아가요
- **더 잘 보이게**: 글자만 있던 메뉴와 링크에 아이콘을 붙이고, 누르는 곳은 버튼 모양으로
- **키패드에 계산기**: 금액을 적으면서 바로 나누고 더할 수 있게 **÷ × − +** 를 넣었어요 (예: 45000 ÷ 3)
- **집값 볼 때 하락장도 같이**: 이건 아래 내집마련에서 다시 나와요

그리고 에피소드 하나. 예비 남편이 제가 만든 앱이라고 주위에 자랑하려고 보여 줬는데, 열자마자 **우리 자산이 그대로 나와서** 당황했대요. 그래서 자산 화면의 금액은 처음에 흐리게 가려 두고, **눌러야 보이게** 바꿨어요.

## 막혔던 것

### 매달 1일 메일이 안 나갔다

매달 1일에 지난달 요약과 백업 파일을 메일로 보내게 했어요. 내 컴퓨터에서는 잘 나가는데, 서버(Vercel)에 올리니 `535 Username and Password not accepted`로 실패했어요.

- Gmail은 계정 비밀번호가 아니라 **앱 비밀번호**(16자)로 보내야 해요
- 그리고 Vercel 환경변수는 **값을 바꾼 뒤 다시 배포해야** 적용돼요. 원인은 서버에 들어간 값이었어요

배운 것: 내 컴퓨터에서는 되고 서버에서만 안 되면, **같은 값을 내 컴퓨터에서 먼저 확인**하면 원인이 금방 갈려요.

### 무료 서버의 예약 작업

매일 밤 10시에 "오늘 기록 정리하세요" 알림을 보내고 싶었는데, Vercel 무료 플랜의 예약 작업은 **하루 한 번까지**이고 정한 시각보다 **최대 59분 늦게** 돌아요. 시간도 한국 시간이 아니라 세계 표준시(UTC)로 적어야 하고요. 그래서 안내 문구도 "밤 10시"가 아니라 "밤 10시대"예요.

### 아이폰 알림

웹 앱의 푸시 알림은 아이폰에서 **홈 화면에 추가한 앱으로 열었을 때만** 돼요 (iOS 16.4 이상). 사파리 탭에서는 안 돼요. 그래서 사용법 문서 맨 앞에 "홈 화면에 추가"를 넣었어요.

### 아파트 실거래가

국토교통부 실거래가 API로 관심 지역 아파트 거래를 받아요. 두 군데서 걸렸어요.

- 공공데이터포털에서 받은 인증키를 그대로 넣으면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 나요. 이미 인코딩된 키라서, 한 번 풀어서 넣어야 했어요
- 실거래 신고 기한이 계약 후 30일이라 **최근 한두 달은 거래가 덜 들어와 있어요**. 그래서 매달 받을 때 지난 석 달 치를 다시 받아 덮어써요

단지마다 세대수를 붙이려고 한국부동산원 단지 자료와 짝을 지었는데, 처음엔 **절반 정도만** 맞았어요. 실거래 자료의 지번에 부번이 붙어 있거나 아예 비어 있는 단지가 많았거든요. 본번만 같은 필지, 같은 동에 이름과 건축년도가 같은 단지 순으로 넓혀서 거의 다 맞췄어요.

## 그리고 내집마련

가장 궁금했던 "이 돈으로 집을 살 수 있나"는 따로 앱을 만들지 않고 **가계부 안에** 넣었어요. 이미 쌓인 자산과 현금 흐름을 그대로 쓰려고요.

- 움직일 수 있는 돈과 대출 조합으로 살 수 있는 최대 집값, 매달 갚을 돈이 수입에 비해 괜찮은지
- 매물 사이트는 공개 API가 없고 긁어 오는 건 약관 위반이라, 대신 **실제 거래된 가격**으로 관심 지역 흐름을 봐요
- 예비 남편 아이디어로, 단지마다 **하락장(2022년 하반기 ~ 2023년)에도 거래가 됐는지** 표시해요. 얼마나 떨어졌는지보다, 그때도 사고팔렸는지를 먼저 보기로 했어요

| 날짜 | 만든 것 |
| --- | --- |
| 9월 30일 | 입력, 고정비, 자산, 통계, 목표, 백업, 로그인, 홈 화면 앱 |
| 10월 2일 | 경로 표시, 설정 카드, 유동 가능 금액 |
| 10월 6일 | 정리 메일, 밤 알림, 저축 흐름, 내집마련 계산기와 관심 지역 집값 |
| 10월 7~8일 | 금액 가리기, 사칙연산 키패드, 끌어서 순서 바꾸기, 기기별 알림, 단지 세대수 |
| 10월 12일 | 단지 검색, 하락장 거래 확인 |

다음은 관심 매물을 직접 넣어 두고, 매물마다 "살 수 있나"를 바로 계산해 보는 기능이에요.
